# File Scanner

A web app that scans a project's files for hard-coded secrets and insecure
environment configurations.

## Features
- Detects hard-coded secrets (API keys, passwords, tokens)
- Checks environment file configurations
- Shows scan findings in a web interface

## Tech Stack
Node.js, Express, React, Tailwind CSS

## How to Run
1. Clone the repo: `git clone <repo-link>`
2. Backend: `cd Backend && npm install && npm start`
3. Frontend: `cd Frontend && npm install && npm run dev`
